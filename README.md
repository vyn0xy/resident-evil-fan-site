# Resident Evil Fan Site

Фанатский сайт по вселенной Resident Evil. Здесь собраны материалы об играх и персонажах серии, а также мини-игры для проверки знаний и внимательности.

**Сайт:** https://vyn0xy.github.io/resident-evil-fan-site/

> Неофициальный фанатский проект. Он не связан с Capcom.

## О сайте

Сайт объединяет несколько разделов, посвящённых серии Resident Evil:

- **Главная** — знакомство с проектом и переход к основным разделам.
- **Игры** — информация об играх серии.
- **Персонажи** — галерея героев и других персонажей.
- **Лучшие игры** — редакционная подборка игр серии.
- **Мини-игры** — отдельные испытания по вселенной Resident Evil.

Интерфейс доступен на русском и английском языках. Для удобной навигации между страницами предусмотрены переходы и кнопки возврата.

## Мини-игры

- **Викторина по вселенной** — вопросы о персонажах, событиях и играх серии. Вопросы распределены по уровням «Знаток» и «Эксперт».
- **Угадай персонажа по тексту** — досье с подсказками. За правильный ответ с меньшим количеством подсказок начисляется больше очков.
- **Угадай персонажа по фотографии** — визуальное испытание с вариантами ответа.
- **Кто ты?** — игровой тест, который определяет персонажа по выбранным ответам.
- **История выживания** — сюжетное испытание с выбором действий.
- **Карточки памяти** — игра на поиск пар персонажей.

В играх есть обратная связь после ответа, а для некоторых режимов — разбор ошибок и повторное прохождение.

## Прогресс и профиль

Игры доступны без серверной регистрации. Никнейм, результаты и рекорды сохраняются локально в браузере с помощью `localStorage`.

Это означает, что прогресс привязан к конкретному браузеру и устройству. Он не синхронизируется между разными устройствами и не является аккаунтом на сервере.

## Технологии

Проект создан на:

- HTML
- CSS
- JavaScript

Для работы сайта не нужны Django, база данных или отдельный сервер. GitHub Pages размещает статические файлы проекта.

## Запуск на компьютере

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в редакторе кода.
3. Запустите `index.html` через расширение **Live Server** или откройте файл в браузере.

Некоторые функции удобнее проверять через локальный веб-сервер редактора, например Live Server.

## Изображения

Изображения сайта находятся в папке `assets/images/`. Внутри есть отдельные папки для главной страницы, игр, персонажей и мини-игр.

Чтобы заменить изображение, добавьте новый файл в подходящую папку и обновите путь к нему в HTML или JavaScript, где это изображение используется.

## Обновление сайта

После изменений в локальных файлах:

1. Сохраните изменения.
2. Создайте коммит в GitHub Desktop.
3. Нажмите **Push origin**, чтобы отправить изменения в GitHub.
4. GitHub Pages автоматически обновит сайт после публикации.

## Статус проекта

Проект предназначен для локальной проверки через Live Server и публикации на GitHub Pages. Никнеймы и игровые рекорды хранятся в браузере посетителя.
