# Ваши фотографии персонажей

Добавляйте сюда свои JPG, PNG или WebP. Существующие портреты галереи менять не нужно.

Пример: положите `leon.webp` в эту папку и откройте `Resident Evil (Project)/character-photos.js`:

```js
leon: 'assets/images/minigames/character-portraits/leon.webp',
```

Все 22 идентификатора уже перечислены в этом файле, включая `luis` (Луис Серра) и `krauser` (Джек Краузер). Для исходных 20 персонажей `null` оставляет демонстрационный портрет из `game-data.js`; для двух новых — подключённое изображение из этой папки. Путь задаётся относительно `photo.html`; учитывайте регистр букв и расширение. Изменение фотографии не влияет на текстовые досье, галерею, вопросы и рекорды.

Изображение показывается целиком, без обрезки и размытия. Если новый путь не загрузится, игра попробует существующий демонстрационный портрет и покажет уведомление. При замене файла с тем же именем обновите страницу через Ctrl+F5. Не добавляйте имя персонажа непосредственно на изображение, если хотите сохранить сложность.

## Подключённая подборка — 7 ноября 2026

Файлы подготовлены обычной обрезкой краёв до квадрата 1:1, без ИИ-перерисовки, фильтров, растягивания и увеличения разрешения. Уже квадратные оригиналы скопированы без перекодирования.
